# Roadmap

## Near Term

- improve retrieval ranking for mixed structured and natural-language queries
- add explicit bulk import commands beyond `capture --apply-extract`
- add export and backup commands
- add richer project-state summarization

## Medium Term

- support more import formats
- add optional embeddings without making them mandatory
- add configurable memory namespaces
- improve cross-platform installer flows

## Long Term

- deeper Codex plugin integration when more lifecycle hooks become available
- optional team-shared memory patterns
- stable public releases with broader install docs
