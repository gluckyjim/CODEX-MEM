# Publishing Guide

## Before Publishing

- review `README.md`
- review `pyproject.toml`
- ensure `state/` is not committed
- run the test suite
- check that example files do not contain private data

## Recommended First Release

- tag `v0.1.0`
- describe the project as an MVP for Codex persistent memory workflows
- include both the motivation and the current limitations

## Suggested Repo Topics

- `codex`
- `memory`
- `sqlite`
- `agent-workflow`
- `developer-tools`
