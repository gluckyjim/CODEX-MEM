# Code of Conduct

## Our Standard

We want `codex-mem` to be a respectful, practical, and constructive project.

Examples of behavior that helps:

- being respectful and patient
- giving actionable technical feedback
- assuming good intent
- focusing on making the tool more useful

Examples of unacceptable behavior:

- harassment or personal attacks
- hostile or demeaning language
- publishing private information without permission
- derailing collaboration in bad faith

## Enforcement

Project maintainers may remove comments, issues, or contributions that violate this code of conduct.
